# ocean 🌊

tiny 2d animated ocean page — for dark rooms, made this because idk im BORED

- animated sky (day/night cycle, sun/moon, clouds, stars)
- layered ocean waves + reflection
- dive underwater for fish, coral, seaweed
- settings menu for sound, day/night, and feedback
- background music: `DeepBlue.wav` → `assets/slime-sea-sunlit-waves.mp3` → `assets/slime-sea-moonlit-calm.mp3` → repeat, with 4-second crossfades (starts on first interaction)

## live

- GitHub Pages: https://iluxz.github.io/ocean/
- githack: https://raw.githack.com/iluxz/ocean/main/index.html

## run locally

open `index.html` in a browser. click anywhere to start audio.

## feedback

use the in-page **send feedback** button. it auto-translates feedback and opens a prefilled GitHub issue draft for legit feedback.
