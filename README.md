# ocean 🌊

tiny 2d animated ocean page — just vibes.

- animated sky (day/night cycle, sun/moon, clouds, stars)
- layered ocean waves + reflection
- dive underwater for fish, coral, seaweed
- settings menu for sound, day/night, and feedback
- background audio: `DeepBlue.wav` (starts on first interaction)

## live

- GitHub Pages: https://iluxz.github.io/ocean/
- githack: https://raw.githack.com/iluxz/ocean/master/index.html

## run locally

open `index.html` in a browser. click anywhere to start audio.

## feedback

use the in-page **send feedback** button. it classifies messages locally (bug/suggestion/spam/harassment) and opens a prefilled GitHub issue draft for legit feedback.
